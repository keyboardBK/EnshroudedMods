# SpeedMod 설치 파일

이 폴더의 `SpeedMod-Setup-0.2.1.exe` 하나를 전달하면 됩니다.
Windows 10/11용이며 게임 클라이언트 빌드 1283531을 지원합니다. 첫 설치는 인터넷이 필요할 수 있습니다.

EML 데이터 패치와 SpeedMod DLL을 포함하고, EML·EMF 공식 배포본은 필요할 때 자동으로 내려받아 검증합니다.
게임 원본 데이터·사용자 설정·세이브는 배포 EXE에 포함하지 않습니다. SHA-256 파일은 이 EXE의 배포 해시입니다.

설치기는 검증됐지만 모드는 개발 버전이며 실제 신발 효과·거래·저장·멀티플레이 검증은 남아 있습니다.
모드를 제거하기 전에 변형된 신발을 복구해야 합니다.
