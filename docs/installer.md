# Windows 설치 프로그램

[SpeedMod-Setup-0.2.1.exe 다운로드](https://github.com/keyboardBK/EnshroudedMods/raw/refs/heads/feature/random-boot-sprint/SpeedMod/distribution/SpeedMod-Setup-0.2.1.exe)

Windows 10/11용 단일 EXE입니다. 받는 사람은 게임을 종료한 후 EXE에서 게임 폴더를 확인하고 **설치 / 업데이트**를 누르면 됩니다. Steam 라이브러리에서 게임 위치를 자동으로 찾으며 직접 선택할 수도 있습니다. 별도 .NET SDK 설치나 PowerShell 명령 입력은 필요하지 않습니다.

설치기 버전은 1.0.0, 포함된 모드는 **0.2.1-alpha**입니다. 게임 클라이언트 빌드 **1283531**만 지원합니다. 전용 서버 실행 파일은 지원하지 않습니다.

## 포함 파일과 다운로드

EXE에는 SpeedMod의 부트스트랩·런타임 DLL, Lua 데이터 패치, 기본 설정과 설치 코드·라이선스가 들어 있습니다. 게임 원본 데이터나 세이브는 포함하지 않습니다. 신발 데이터는 받는 PC의 게임 파일에서 생성합니다.

필요한 EML 0.2.0과 EMF 0.3.5는 **공식 GitHub 릴리스**에서 자동으로 내려받습니다. 버전과 SHA-256을 고정하며, 다른 내용의 파일은 실행·설치하지 않습니다. 정확히 같은 구성요소가 이미 있으면 검증 후 재사용합니다. 처음 설치할 때 인터넷 연결이 필요할 수 있습니다.

EML은 외부 프로그램·로더로 별도 다운로드하며 설치기에 바이너리를 묶지 않습니다. 관련 GPL-3.0 라이선스와 공식 소스 주소를 설치 폴더에 제공합니다. EMF의 로더·코어·필수 설정만 설치하며 관련 라이선스도 제공합니다. 다른 EMF 내장 모드나 모드 매니저는 자동 설치하지 않습니다.

## 설치 동작

1. 게임 실행 파일의 정확한 SHA-256과 실행 중인 게임·모드 매니저를 확인합니다.
2. 구성요소를 준비하고, 내장 파일과 다운로드한 배포본의 해시를 검증합니다.
3. 기존 KFC·리소스·캐시·연결 설정을 백업합니다. 발견한 Steam/로컬 저장 파일도 읽어서 복사·검증하며, 원본 저장 파일이나 Steam Cloud 설정은 바꾸지 않습니다.
4. 기존 다른 dinput8 로더는 보존 후 연결합니다. 중복 실행될 EML은 백업·비활성화하고 부트스트랩이 EML보다 먼저 실행되게 설정합니다. 다른 모드 폴더는 삭제하지 않습니다.
5. 기존 SpeedMod `config.ini`는 유지하고, EML을 실행해 전체 신발 데이터를 생성합니다.
6. 성공하면 설치 기록을 저장합니다. 실패하면 변경한 파일과 캐시를 되돌리고 이번에 만든 빈 모드 폴더도 정리합니다. 강제 종료·정전까지 자동 복구를 보장하지는 않습니다.

백업은 `<게임 폴더>/SpeedModInstaller/backups/<날짜-고유번호>/`에 남습니다. 설치 결과·구성은 `SpeedModInstaller/install-state.json`, 패치 로그는 해당 백업 폴더의 `patch.log`에서 확인할 수 있습니다.

다른 EMF 버전이나 지원하지 않는 실행 파일은 자동으로 덮어쓰지 않습니다. 링크된 폴더는 실제 폴더 경로를 선택해야 합니다. 쓰기 권한이 부족하면 설치 창에 관리자 권한으로 다시 실행하는 버튼을 표시합니다. 디지털 서명이 없는 개발용 EXE입니다.

## 검증과 남은 범위

- 단일 EXE 빌드·압축 해제, 한글 설치 화면, Steam 라이브러리 자동 탐색, 실제 게임 버전 검사 확인.
- 모의 패치 도구를 이용한 처음 설치·반복 설치·기존 설정 및 다른 로더/모드 보존 테스트 통과.
- 파일 복사 후 실패·패치 후 실패·패치 도구 오류에서 원래 로더·KFC·리소스·캐시·연결 설정 복구 확인. 변조 파일·미지원 버전·경로 이탈 거부 확인.
- 별도 한글·공백 경로의 원본 데이터 복사본에서 실제 공식 다운로드·해시 검증·EML 전체 데이터 생성 완료.
- 현재 게임 폴더에 실제 EXE로 업데이트 완료. 실행 파일·사용자 설정·기존 연결 설정의 해시 유지 확인. 발견한 저장 파일 7개 백업.
- 설치 EXE로 업데이트한 실제 게임에서 모드 0.2.1 로드·메뉴 화면·561프레임 진행 확인. 월드는 열지 않았습니다.
- **설치기 검증과 모드의 게임 플레이 검증은 별개입니다.** 실제 신발 효과·툴팁, 거래·창고, 저장·재시작과 멀티플레이 검증은 아직 남아 있습니다.

모드 제거 전 신발 복구 절차는 [README](../README.md)를 따릅니다. 설치 이전 KFC를 플레이 후 무작정 복원하면 저장된 변형 신발이 유실될 수 있으므로 설치 백업을 일반 제거 기능으로 사용하지 마세요.

## 개발자 빌드와 검사

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File SpeedMod/installer/build-installer.ps1
```

Visual Studio C++ Build Tools로 네이티브 DLL을 빌드·검사하고 Windows의 .NET Framework C# 컴파일러로 설치기를 만듭니다. 네이티브 DLL을 이미 빌드했다면 `-SkipNativeBuild`를 쓸 수 있습니다. 빌드 결과는 `SpeedMod/package/SpeedMod-Setup-0.2.1.exe`입니다.

```text
SpeedMod-Setup-0.2.1.exe --check --game "D:\Games\Enshrouded" --report check.json
SpeedMod-Setup-0.2.1.exe --extract "D:\Temp\SpeedModPayload"
```

개발자 검사 모드는 실제로 파일을 바꾸지 않는 `--check`, 빈 폴더에 내장 파일을 푸는 `--extract`, UI 없이 설치하는 `--install`을 제공합니다. `--offline`은 검증된 기존 구성요소만 사용하며, `--dependencies`로 별도 공식 배포본 폴더를 지정할 수 있습니다. 일반 사용자는 이 옵션을 입력할 필요가 없습니다.

`installer/tests/Installer.Tests.ps1`은 압축 해제한 패키지와 별도 작업 폴더를 받아 가상 게임·저장 폴더에서 동작합니다. 실제 Steam 저장 폴더는 검사하지 않습니다. 테스트용 패치 도구와 실제 EML을 사용한 검증을 구분합니다.
